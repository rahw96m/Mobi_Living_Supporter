# 모비노기 생활 지원도구 (Mobi Living Supporter)

마비노기 모바일 PC 클라이언트의 AI 에이전트 CLI(`MabinogiMobile_CLI`)를 연동하여 주간 납품 의뢰 확인, 재료 계산, 채집, 가공, 제작 과정을 보조하는 유틸리티입니다.

## 다운로드 및 실행

파이썬 설치 없이 윈도우 환경에서 즉시 실행할 수 있는 독립 실행형 패키지를 제공합니다.

1. [GitHub Releases](https://github.com/rahw96m/Mobi_Living_Supporter/releases/latest)에서 최신 압축 파일(`Mobi_Living_Supporter_v0.5.2.zip`)을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 원하는 폴더에 해제합니다.
3. 폴더 내의 `모비노기_생활_지원도구.exe`를 실행하거나 `바탕화면_바로가기_만들기.bat`을 실행합니다.
4. 브라우저에서 대시보드(`http://localhost:8080`)가 자동으로 열립니다. (웹 브라우저 창 종료 시 서버 자동 종료)

> **사전 설정**  
> 게임 실행 후 **[환경설정] - [기타] - [MM AI 에이전트 활성화]** 옵션이 켜져 있어야 합니다.

## 주요 기능

- **개별 아이템 지정 제작 탭 & 통합 플래너 (신규 3번째 메인 탭)**: 주간 납품, 7슬롯 빠른 가공과 동등한 독립 메인 탭으로 승격. 여러 개의 제작 목표 아이템과 수량을 누적 등록하면 주간 납품처럼 **통합 플래너가 모든 하위 재료(원자재 채집 + 1차 가공)를 일괄 분석(BOM)**하고, [일괄 가공 & 제작 시작] 원스톱 파이프라인 가동 후 마지막에 **작업 완료 리포트(요약 모달)**를 제공.
- **벌목 & 통나무/나무 진액 스마트 최적 채집 & 단계적 폴백**: **나무 진액은 뾰족 나무**, **통나무는 굵은 나무** 등 항상 필요한 재료를 가장 빨리 확보할 수 있는 최적의 나무를 자동으로 타겟팅. 캐릭터의 벌목 레벨이 부족할 경우 에러 없이 **하위 나무로 단계적 자동 폴백**.
- **양털 계열 스마트 최적 채집 & 단계적 폴백**: 양털은 일반 양, 상급 양털은 곱슬 양, 상급 양털+는 먹구름 양 등 항상 최다 드롭 대상을 자동으로 타겟팅. 양털 깎기 레벨 미달 시 **하위 양으로 단계적 자동 폴백**.
- **가공 우선순위 설정 (상위 티어 / 하위 티어 우선 선택)**: 가공 시간이 오래 걸리는 고티어 재료부터 우선 등록(기본값, T7 ➔ T1)하거나 하위 기초 재료부터 순차 제작(T1 ➔ T7)하도록 웹 UI 및 CLI에서 간편하게 전환 및 설정 유지.
- **주간 납품 & 7슬롯 가공대 & 개별 제작 탭 분리 UI**: 한 화면에 길게 나열되던 기능들을 3대 상단 탭으로 즉시 전환하여 집중도와 작업 편의성을 극대화. (선택 탭 자동 기억)
- **공식 전용 프로그램 아이콘 및 UI 일체감**: 마비노기 생활 감성의 전용 앱 아이콘(`.exe`, 바로가기, 브라우저 탭 파비콘, 헤더 로고) 탑재.
- **반응형 2단 헤더 대시보드**: 상단 타이틀/유틸리티 액션 바와 하단 캐릭터 상태 바(연결 상태, 날개, 무게)를 분리하여 가독성을 높이고 화면 크기에 따라 반응형 아이콘 모드 지원.
- **주간 납품 목표 관리 및 BOM 계산**: 추적 중인 납품 퀘스트 등록 또는 아이템명 직접 입력, 프리셋 저장/불러오기, 새 주간을 위한 **보유 수량 0개 일괄 초기화** 지원.
- **스마트 제작 및 과잉 생산 방지**: 1회당 산출량(PPC) 및 대성공(크리티컬) 보상을 실시간 계산하여 목표 수량 달성 시 즉시 제작을 완료(초과 제작 및 날개 낭비 원천 차단).
- **장비 및 특수 아이템 수량 영구 보존**: 인게임 인벤토리 조회에서 누락되는 무기/방어구/키트류의 수량이 0개로 덮어써지지 않고 안전하게 보존.
- **가방 및 창고 수량 통합 확인**: 캐릭터 가방(`inventory`), 개인 창고(`character_storage`), 계정 공용 창고(`account_storage`)의 보유량을 합산하여 부족한 수량만 계산.
- **가공 완료품 자동 수령**: 새로운 가공 작업을 등록하기 전, 시설에 완료된 가공품이 있으면 먼저 수령하여 슬롯을 확보.
- **가공대 일괄 루틴**: 금속, 목재, 가죽, 옷감 가공대의 7개 슬롯에 맞춰 우선순위 설정에 따라 순차적으로 일괄 가공을 진행.
- **웹 대시보드 및 콘솔 지원**: 브라우저 기반 대시보드 및 터미널 콘솔(CLI) 모드를 지원.

## 소스코드 실행 방법 (개발용)

```bash
# 웹 대시보드 실행
python web_server.py

# 터미널 콘솔 실행
python app.py
```

## 파일 구성

- `web_server.py`: 로컬 웹 서버 및 대시보드 인터페이스
- `delivery_manager.py`: 납품 데이터 관리 및 채집/가공/제작 파이프라인
- `mabi_cli.py`: MabinogiMobile_CLI 연동 래퍼
- `app.py`: 콘솔 CLI 실행기
- `package_dist.py`: PyInstaller 기반 배포 패키지 빌드 스크립트
