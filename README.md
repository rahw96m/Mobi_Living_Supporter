# 🗡️ Mobi_Living_Supporter (마비노기 모바일 생활 & 납품 서포터)

마비노기 모바일 AI 커넥터(`MabinogiMobile_CLI`)를 활용하여 **주간 납품 의뢰를 감지하고, 부족한 재료의 채집 ➔ 가공 ➔ 최종 제작까지 전자동으로 수행**하는 생활/납품 서포터 프로그램입니다.

---

## 🌟 주요 기능

1. **주간 납품 목표 누적 등록 & 통합 일괄 플래너 (Multi-Task Accumulator)**
   - 게임 클라이언트가 현재 추적 중인 퀘스트만 반환하는 제약을 극복하기 위해 **목표 누적 등록 시스템**을 제공합니다.
   - **인게임 퀘스트 순차 등록**: 인게임에서 퀘스트를 하나씩 추적하면서 웹에서 `[➕ 현재 퀘스트 등록]`을 누르면 목록에 차례대로 누적 저장됩니다.
   - **아이템명/수량 직접 등록**: 퀘스트를 변경하지 않고도 아이템명과 목표 수량을 직접 입력하여 등록할 수 있습니다.
   - **통합 소요량 산출(BOM)**: 등록된 모든 주간 납품 아이템의 레시피를 합산하여 필요한 1차 가공품을 일괄 가공하고 원클릭으로 순차 최종 제작합니다.

2. **📦 가방 + 개인 창고 + 계정 공용 창고 수량 통합 파악**
   - 게임 내에서는 창고에 있는 재료를 꺼내지 않고도 즉시 제작/가공에 사용할 수 있으므로, **캐릭터 가방(`inventory`), 개인 창고(`character_storage`), 계정 공용 창고(`account_storage`)의 보유량을 모두 합산하여 정확한 소요량을 계산**합니다.
   - 대시보드 화면 및 콘솔 로그에서 `(가방 X + 개인창고 Y + 공용창고 Z)` 형태로 각 위치별 수량을 투명하게 확인할 수 있습니다.

3. **🎁 가공 전 완료 슬롯 자동 우선 수령 (Auto-Collect Completed Altering)**
   - 모든 가공(개별 가공, 일괄 납품 가공, 7슬롯 빠른 가공 등)을 등록하기 전, **완료된 가공 슬롯이 감지되면 해당 시설의 완료 가공품을 먼저 수령**하여 슬롯을 비우고 가방에 결과물을 확보한 뒤 새 가공 작업을 맡깁니다.

4. **자유 아이템 지정 제작 (Custom Crafting)**
   - 예: `로터스 힐링 완드 6개`와 같이 아이템명과 목표 수량만 입력하면:
     - 현재 가방 및 창고(개인/공용) 전체 보유량 확인
     - 필요 수량 계산
     - 부족한 원자재 자동 채집 (`execute_gathering`)
     - 중간 가공 전 완료품 수령 ➔ 가공 대기열 등록 및 완료 수령 (`execute_altering` ➔ `complete_altering_work`)
     - 시설 이동 및 최종 완제품 일괄 제작 (`execute_crafting`)

3. **⚡ 7슬롯 최고 레벨 가공대 빠른 실행 (Quick Facility Routine)**
   - 최고 레벨 가공대의 7개 슬롯에 맞춰 **완료된 가공품 일괄 수령 ➔ 부족한 원자재 사전 일괄 채집 ➔ 최고 티어(T7~T1)부터 순차 가공**을 원클릭으로 수행합니다.
   - **4대 주요 가공대 지원**:
     - 🪙 **금속**: 백금강괴(T7) ~ 운철괴 ~ 은합금괴 ~ 특수강괴 ~ 합금강괴 ~ 강철괴 ~ 철괴(T1)
     - 🪵 **목재**: 특급 목재(T7) ~ 최상급 목재+ ~ 최상급 목재 ~ 상급 목재+ ~ 상급 목재 ~ 목재+ ~ 목재(T1)
     - 🦊 **가죽**: 특급 가죽(T7) ~ 최상급 가죽+ ~ 최상급 가죽 ~ 상급 가죽+ ~ 상급 가죽 ~ 가죽+ ~ 가죽(T1)
     - 🧶 **옷감**: 특급 옷감(T7) ~ 최상급 옷감+ ~ 최상급 옷감 ~ 상급 옷감+ ~ 상급 옷감 ~ 옷감+ ~ 옷감(T1)
   - **스마트 재료 판별**:
     - 채집 가능한 원자재(광석, 통나무, 양털 등)는 가공 전 사전에 모두 필드 채집!
     - 가공으로만 얻을 수 있는 중간 재료(하위 가공품 등)가 부족한 티어는 에러 없이 자동으로 건너뜀(Skip).

4. **듀얼 인터페이스 지원**
   - **웹 대시보드 (Web UI)**: 브라우저(`http://localhost:8080`)에서 7슬롯 빠른 가공 현황, 주간 납품 플래너, 가공 대기열, 실시간 콘솔 시각적 확인. **브라우저 창을 닫으면 백그라운드 서버도 안전하게 자동 종료**됩니다.
   - **터미널 콘솔 (CLI)**: 대화형 메뉴(5번 메뉴) 및 커맨드라인 직접 실행 (`python app.py --quick-alter all`).

## 🚀 실행 방법

### 방법 1. 웹 대시보드로 실행 (추천 ✨)
```bash
python web_server.py
```
또는
```bash
run_web.bat
```
브라우저에서 **`http://localhost:8080`**으로 접속합니다.

### 방법 2. 커맨드라인에서 바로 제작
```bash
python app.py "로터스 힐링 완드" 6
```

### 방법 3. 콘솔 대화형 메뉴로 실행
```bash
python app.py
```

## 📂 파일 구조
- `mabi_cli.py`: Mabinogi Mobile AI 커넥터 CLI 래퍼 (UTF-8/Base64 인코딩, JSON 파싱)
- `delivery_manager.py`: 납품 퀘스트 감지, 레시피/재료 트리 추적, 채집/가공/제작 오케스트레이션 엔진
- `app.py`: 콘솔 CLI 실행기
- `web_server.py`: 현대적인 다크 글래스모피즘 웹 대시보드 서버
