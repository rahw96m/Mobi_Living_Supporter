# 모비노기 지원도구 (Mobi Supporter)

마비노기 모바일 PC 클라이언트의 AI 에이전트 CLI(`MabinogiMobile_CLI`)를 연동하여 주간 납품 의뢰 확인, 재료 계산, 채집, 가공, 제작 과정을 보조하는 유틸리티입니다.

## 다운로드 및 실행

파이썬 설치 없이 윈도우 환경에서 즉시 실행할 수 있는 독립 실행형 패키지를 제공합니다.

1. [GitHub Releases](https://github.com/rahw96m/Mobi_Living_Supporter/releases/latest)에서 최신 압축 파일(`Mobi_Living_Supporter_v2.0.3.zip`)을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 원하는 폴더에 해제합니다.
3. 폴더 내의 `모비노기_생활_지원도구.exe`를 실행하거나 `바탕화면_바로가기_만들기.bat`을 실행합니다.
4. 브라우저에서 대시보드(`http://localhost:8080`)가 자동으로 열립니다. (웹 브라우저 창 종료 시 서버 자동 종료)

> **사전 설정**  
> 게임 실행 후 **[환경설정] - [기타] - [MM AI 에이전트 활성화]** 옵션이 켜져 있어야 합니다.

## 주요 기능

- **중복 이모지 제거 및 터미널 스타일 UI 일체화 (v2.0.3 신규)**: 상단 모드 스위처(`[생활 지원]`, `[숙제 지원]`), 상태 바 결계 알림, 주간 납품 연동 행 등에서 중복되던 불필요한 OS 이모지를 모두 걷어내고 정갈한 플랫 텍스트 스타일로 통일. 마스터 커맨드 바 완료 버튼에서 단축키가 없는 주간 항목의 대괄호(`[,]`) 제거.
- **숙제 설정 편집 포커스 보존 및 플랫 단축키 키캡 UI (v2.0.2 신규)**: 실시간 인게임 동기화 폴링 중 숙제 설정 탭(`hw-subview-settings`)의 input 요소가 덮어씌워져 커서가 비활성화되던 문제를 완벽 차단(포커스 보호 및 선택적 렌더링), 숙제 이름 입력 및 캐릭터 입력창에서 Enter 키로 즉시 저장 지원, 단축키 키캡(`[J]`, `[/]` 등)을 생활 지원도구 테마와 일체화된 플랫(Flat) 디자인으로 개편.
- **인게임 숙제 실시간 자동 감지 고도화 & 백그라운드 텔레메트리 루프 (v2.0.1 신규)**: 사냥터 및 정기 의뢰(`[주간 목표] 모험가 길드의 정기 의뢰` 진행 카운트 정규화), 검은 구멍(`구석구석 깨끗하게` 등 미션 설명 통합 검색), 요일 던전(`빛나는 동굴`, `눈부신 저택`, `찬란한 유적` 환경 맵 자동 추적) 클리어 자동 체크 판정을 완벽하게 보강하였으며, 브라우저가 최소화되거나 백그라운드에 있어도 감지를 놓치지 않는 서버 텔레메트리 백그라운드 루프 탑재.
- **생활 지원 ↔ 숙제 지원 통합 대시보드 & 캐릭터 프로필 일원화 (v2.0.0 신규)**: 상단 헤더의 `[⚒️ 생활 지원]` ↔ `[📋 숙제 지원]` 최상위 스위처로 두 모드를 즉시 전환할 수 있으며, 기존 숙제 오버레이의 다캐릭터 프로필과 주간 납품 캐릭터 프로필을 하나로 통합 공유합니다. 일일/집중(06:00 KST) 및 주간(월요일 06:00 KST) 자동 초기화, 단계별 숙제 진행 브리핑 및 되돌리기, 전체 캐릭터 종합 현황표, 주간 숙제 매트릭스 체크표, 캐릭터별 메모장, 인게임 실시간 스펙/재화/미션/던전/어비스 자동 완료 감지, 매시간 정각 불길한 소환의 결계 알림 타이머를 지원합니다.
- **캐릭터별 주간 납품 독립 관리 & 월요일 06시 자동 초기화 (v1.4.1 신규)**: 다캐릭터 프로필별 주간 납품 목록·보유 수량을 완전 독립 관리하며, 인게임 접속 캐릭터(`직업·생활력`) 감지 시 자동 탭 전환, `[✓ 납품 완료]` 시 목표 수량만큼 보유량 자동 차감 및 매주 월요일 오전 6시(KST) 완료 배지 자동 리셋, 드래그 앤 드롭 및 `<` `>` 버튼으로 납품 카드 순서 변경 지원.
- **단일 연속 작업 55분 주기 자동 리프레시 (v1.4.0 신규)**: 장시간 단일 채집 또는 자동 낚시 진행 시 인게임 1시간 연속 작업 확인 팝업이 뜨기 전에 55분(3,300초)마다 행동을 안전하게 중단(`stop_action`) 후 즉시 재개하여 무중단 자동화 안정성 극대화.
- **AI 편의 도구함 & 스마트 생활 자동화 확장 (v1.4.0 신규)**: 스마트 자동 낚시, 악보 자동 연주, 보관함 선택형 회수(우편함·캐시샵 보관함·모험가 패스 목록 선택 수령), 미니 플로팅 전광판(Mini HUD), 스마트폰 QR 원격 대시보드, 가방 무게 가드 & 창고 자동 정리(옵션), 포션/음식/수리비 사전 안전 점검(옵션) 탑재.
- **레시피 검색 초성/역방향 자동완성 & 인터랙티브 BOM 트리 (v1.4.0 신규)**: 한글 초성 검색(`ㄹㅌㅅ` → `로터스 힐링 완드`), 하위 재료 역방향 검색, 클릭 가능한 하위 재료 칩, 최근 검색어 태그 및 `+ 납품목표` / `+ 지정제작` 원클릭 연동.
- **전체 통합 성능 최적화 (v1.4.0 신규)**: CLI 조회 캐싱 및 병렬 프리페치, 프론트엔드 폴링 최적화, 콘솔 DOM 가상 제한 및 Gzip 압축 전송으로 메모리·CPU 점유율 대폭 절감.
- **사용 가이드 & 단계별 실전 튜토리얼 모달 탑재 (v1.3.0 신규)**: 처음 사용하는 길드원이나 초보자도 1분 만에 적응할 수 있도록 사전 필수 설정, 주간 납품 18개 한 번에 끝내기 5단계 실전 가이드, 디스코드 웹훅 알림 3단계 연동법, 7슬롯 가공/개별 제작 팁을 웹 대시보드 상단 `[사용 가이드 & 튜토리얼]` 모달에서 원클릭 제공.
- **주간 납품 핵심 18개 기본 세팅 & 자동 초기화 (v1.3.0 신규)**: 프로그램 최초 실행 시 빈 화면 대신 실전에서 가장 많이 쓰이는 18개 핵심 주간 의뢰(로터스 힐링 완드, 론 엣지소드S, 양털, 달걀, 우유 등)가 자동 등록되어 즉시 사용 가능.
- **캐릭터 직업명 연동 & 상태 바 가독성 튜닝 (v1.3.0 신규)**: 서버명 대신 현재 접속 중인 캐릭터의 직업(예: `화염술사 (Lv.100)`)이 우선 표시되며, 폰트 메트릭 간격을 조정하여 레벨 뒤 불필요한 공백을 완전히 제거.
- **스피너 브래킷 위치 완전 고정 (v1.3.0 신규)**: 작업 진행 시 `[`와 `]` 양쪽 괄호가 좌우로 덜컹거리지 않도록 위치를 고정하고, 내부 회전 문자만 고정폭 안에서 부드럽게 돌아가도록 시각적 안정성 극대화.
- **목표 완수 모드 디스코드 웹훅 알림 연동 (v1.2.0 신규)**: 주간 납품 또는 개별 지정 제작을 [목표 완수 모드]로 실행 시, 자리를 비우더라도 채집/가공/제작 등 모든 작업이 완료(100% 달성 또는 가용 작업 완료)되면 디스코드 채널로 작업 소요 시간, 날개 소모량, 완성 아이템 및 가공/채집 결과 요약 리포트를 실시간 웹훅으로 자동 전송. (웹 UI 상단 상태 바 및 마스터 커맨드 바에서 원클릭 설정/테스트 지원)
- **다크모드 소프트 대비 & 편안한 웜그레이 테마 전환 (v1.1.1 신규)**: 장시간 사용 시 눈부심과 눈 피로를 최소화하도록 다크모드의 고대비 텍스트를 차분한 소프트 펄 실버로 정밀 튜닝하였으며, 헤더의 `다크모드 ON/OFF` 버튼으로 미세한 웜(노란빛) 틴트가 감도는 편안한 웜그레이 테마로 즉시 전환 및 자동 저장 지원.
- **모던 CLI & 터미널 다크 테마 시스템 (v0.7.0 신규)**: Pretendard 본문과 JetBrains Mono 고정폭(Monospace) 폰트 기반의 미니멀 럭셔리 다크 테마 전면 개편. 수치 변동 시 흔들림 없는 `tabular-nums`, CLI 스타일 텍스트 게이지(`[■■■□□]`), 실시간 상태 스피너, 정돈된 구분선(`//`, `>`, `::`)으로 심미성과 정보 집중도 극대화.
- **실시간 가공 대기열 동기화 & 1초 카운트다운 타이머 (v0.7.0 신규)**: 가공 작업 진행 중에도 대기열 슬롯 상태를 실시간 캐시로 즉각 공유하고, 브라우저가 백그라운드에 있어도 스로틀링 없는 Web Worker 기반 1초 카운트다운 타이머 연동으로 가공 완료 알람 및 남은 시간 정확 제공.
- **마스터 커맨드 바 실시간 파이프라인 ETA & 완수 시각 프리뷰 (v0.7.0 신규)**: 주간 납품 및 개별 제작 시 [목표 완수 모드] 활성화 여부에 따라 총 예상 소요 시간 및 목표 완수 예정 시각을 실시간 계산하여 헤더 배너 및 실행 확인창에 정밀 안내.
- **사용자 데이터 영구 보존 & 버전 업데이트 프리**: 사용자가 학습/등록한 레시피, 주간 납품 프리셋, 개별 제작 목표, 가공 순서 설정 등이 **`내 문서\MobiLivingSupporter`**에 영구 저장됩니다. 프로그램 버전이 업데이트되어 새 ZIP 파일을 받아도 기존 설정이 100% 자동 유지되어 파일을 수동 복사할 필요가 없습니다. (웹 UI 상단 및 모달에서 `[데이터 폴더]` 원클릭 열기 지원)
- **개별 아이템 지정 제작 탭 & 통합 플래너 (3번째 메인 탭)**: 주간 납품, 7슬롯 빠른 가공과 동등한 독립 메인 탭. 여러 개의 제작 목표 아이템과 수량을 누적 등록하면 주간 납품처럼 **통합 플래너가 모든 하위 재료(원자재 채집 + 1차 가공)를 일괄 분석(BOM)**하고, [일괄 가공 & 제작 시작] 원스톱 파이프라인 가동 후 마지막에 **작업 완료 리포트(요약 모달)**를 제공.
- **벌목 & 통나무/나무 진액 스마트 최적 채집 & 단계적 폴백**: **나무 진액은 뾰족 나무**, **통나무는 굵은 나무** 등 항상 필요한 재료를 가장 빨리 확보할 수 있는 최적의 나무를 자동으로 타겟팅. 캐릭터의 벌목 레벨이 부족할 경우 에러 없이 **하위 나무로 단계적 자동 폴백**.
- **양털 계열 스마트 최적 채집 & 단계적 폴백**: 양털은 일반 양, 상급 양털은 곱슬 양, 상급 양털+는 먹구름 양 등 항상 최다 드롭 대상을 자동으로 타겟팅. 양털 깎기 레벨 미달 시 **하위 양으로 단계적 자동 폴백**.
- **가공 우선순위 설정 (상위 티어 / 하위 티어 우선 선택)**: 가공 시간이 오래 걸리는 고티어 재료부터 우선 등록(기본값, T7 -> T1)하거나 하위 기초 재료부터 순차 제작(T1 -> T7)하도록 웹 UI 및 CLI에서 간편하게 전환 및 설정 유지.
- **주간 납품 & 7슬롯 가공대 & 개별 제작 탭 분리 UI**: 한 화면에 길게 나열되던 기능들을 3대 상단 탭으로 즉시 전환하여 집중도와 작업 편의성을 극대화. (선택 탭 자동 기억)
- **공식 전용 프로그램 아이콘 및 UI 일체감**: 마비노기 생활 감성의 전용 앱 아이콘(`.exe`, 바로가기, 브라우저 탭 파비콘, 헤더 로고) 탑재.
- **반응형 2단 헤더 대시보드**: 상단 타이틀/유틸리티 액션 바와 하단 캐릭터 상태 바(연결 상태, 날개, 무게)를 분리하여 가독성을 높이고 화면 크기에 따라 반응형 아이콘 모드 지원.
- **주간 납품 목표 관리 및 BOM 계산**: 추적 중인 납품 퀘스트 등록 또는 아이템명 직접 입력, 프리셋 저장/불러오기, 새 주간을 위한 **보유 수량 0개 일괄 초기화** 지원.
- **스마트 제작 및 과잉 생산 방지**: 1회당 산출량(PPC) 및 대성공(크리티컬) 보상을 실시간 계산하여 목표 수량 달성 시 즉시 제작을 완료(초과 제작 및 날개 낭비 원천 차단).
- **장비 및 특수 아이템 수량 영구 보존**: 인게임 인벤토리 조회에서 누락되는 무기/방어구/키트류의 수량이 0개로 덮어써지지 않고 안전하게 보존.
- **가방 및 창고 수량 통합 확인**: 캐릭터 가방(`inventory`), 개인 창고(`character_storage`), 계정 공용 창고(`account_storage`)의 보유량을 합산하여 부족한 수량만 계산.
- **가공 완료품 자동 수령**: 새로운 가공 작업을 등록하기 전, 시설에 완료된 가공품이 있으면 먼저 수령하여 슬롯을 확보.
- **가공대 일괄 루틴**: 금속, 목재, 가죽, 옷감 가공대의 7개 슬롯에 맞춰 우선순위 설정에 따라 순차적으로 일괄 가공을 진행.
- **웹 대시보드 및 콘솔 지원**: 브라우저 기반 대시보드 및 터미널 콘솔(CLI) 모드를 지원.

## 소스코드 실행 방법 (개발용)

```bash
# 웹 대시보드 실행

```

## 파일 구성

- `web_server.py`: 로컬 웹 서버 및 대시보드 인터페이스
- `delivery_manager.py`: 납품 데이터 관리 및 채집/가공/제작 파이프라인
- `mabi_cli.py`: MabinogiMobile_CLI 연동 래퍼
- `app.py`: 콘솔 CLI 실행기
- `package_dist.py`: PyInstaller 기반 배포 패키지 빌드 스크립트
