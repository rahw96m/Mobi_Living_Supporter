# 모비노기 생활 지원도구 (Mobi Living Supporter)

마비노기 모바일 PC 클라이언트의 AI 에이전트 CLI(`MabinogiMobile_CLI`)를 연동하여 주간 납품 의뢰 확인, 재료 계산, 채집, 가공, 제작 과정을 보조하는 유틸리티입니다.

## 다운로드 및 실행

파이썬 설치 없이 윈도우 환경에서 즉시 실행할 수 있는 독립 실행형 패키지를 제공합니다.

1. [GitHub Releases](https://github.com/rahw96m/Mobi_Living_Supporter/releases/latest)에서 최신 압축 파일(`Mobi_Living_Supporter_v0.1.1.zip`)을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 원하는 폴더에 해제합니다.
3. 폴더 내의 `모비노기_생활_지원도구.exe`를 실행하거나 `바탕화면_바로가기_만들기.bat`을 실행합니다.
4. 브라우저에서 대시보드(`http://localhost:8080`)가 자동으로 열립니다. (웹 브라우저 창 종료 시 서버 자동 종료)

> **사전 설정**  
> 게임 실행 후 **[환경설정] - [기타] - [MM AI 에이전트 활성화]** 옵션이 켜져 있어야 합니다.

## 주요 기능

- **주간 납품 목표 관리 및 BOM 계산**: 추적 중인 납품 퀘스트를 등록하거나 아이템명을 직접 입력하여 필요한 가공 재료의 소요량을 산출하고 순차 제작합니다.
- **가방 및 창고 수량 통합 확인**: 캐릭터 가방(`inventory`), 개인 창고(`character_storage`), 계정 공용 창고(`account_storage`)의 보유량을 합산하여 부족한 수량만 계산합니다.
- **가공 완료품 자동 수령**: 새로운 가공 작업을 등록하기 전, 시설에 완료된 가공품이 있으면 먼저 수령하여 슬롯을 확보합니다.
- **가공대 일괄 루틴**: 금속, 목재, 가죽, 옷감 가공대의 7개 슬롯에 맞춰 상위 티어부터 순차적으로 일괄 가공을 진행합니다.
- **웹 대시보드 및 콘솔 지원**: 브라우저 기반 대시보드 및 터미널 콘솔(CLI) 모드를 지원합니다.

## 소스코드 실행 방법 (개발용)

```bash
# 웹 대시보드 실행
python web_server.py

# 터미널 콘솔 실행
python app.py
```

## 파일 구성

- `web_server.py`: 로컬 웹 서버 및 대시보드 인터페이스
- `delivery_manager.py`: 납품 데이터 관리 및 채집/가공/제작 파이프라인
- `mabi_cli.py`: MabinogiMobile_CLI 연동 래퍼
- `app.py`: 콘솔 CLI 실행기
- `package_dist.py`: PyInstaller 기반 배포 패키지 빌드 스크립트
